# Seasonal-Agriculture-Performance-Analysis
Major Data Analytics Project – Seasonal Agriculture Performance Analysis

## About the Project
This project analyzes agricultural performance across different seasons
to identify patterns, trends, relationships and differences in crop
performance, resource usage and profitability.

## Dataset
The dataset contains 4,000 records and 28 variables covering:
- Farm information
- Environmental conditions
- Soil characteristics
- Farming practices
- Crop production
- Water usage
- Revenue and profit
The analysis covers Kharif, Rabi and Zaid seasons.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel

## Analysis Performed
- Data loading and exploration
- Data cleaning
- Missing-value handling
- Descriptive statistics
- Univariate analysis
- Outlier analysis
- Bivariate analysis
- Multivariate analysis
- Correlation analysis
- Seasonal comparison
- Crop-season analysis
- Irrigation analysis
- Water usage and efficiency analysis
- Profitability analysis

## Key Findings
- Kharif showed the highest average yield and profitability.
- Zaid showed the lowest average profit.
- Zaid also had the highest average water usage.
- Yield and water efficiency showed a strong positive relationship.
- Yield and production showed a strong positive relationship.
- Profitability varied considerably across irrigation methods and seasons.
- Negative-profit cases were most common in the Zaid season.
